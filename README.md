
# SaveForest - Forest Conservation Website

## Project Overview

SaveForest is a responsive forest conservation website designed to spread awareness about forests, wildlife, biodiversity, and environmental protection. It features realistic forest photography, a nature-inspired design, interactive elements, and information about the importance of protecting our planet.

The website is developed using HTML, CSS, and JavaScript and can be deployed on a cloud-based virtual machine such as Microsoft Azure.

## Project Aim

To develop an attractive and responsive website that promotes forest conservation, spreads environmental awareness, and encourages people to take action toward a greener and more sustainable future.

## Objectives

- Spread awareness about forest conservation.
- Highlight the importance of forests and biodiversity.
- Present wildlife information through visual cards.
- Display environmental statistics using animated counters.
- Encourage users to participate in conservation activities.
- Create a responsive website accessible on desktops, tablets, and mobile devices.
- Learn the fundamentals of website development and cloud deployment.

## How to Run the Project

### Method 1: Using a Web Browser

1. Download or clone the project repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.

### Method 2: Using Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if required.
3. Open `index.html`.
4. Right-click inside the editor.
5. Select "Open with Live Server".

The website will open in your browser.

## Deployment on Microsoft Azure

The website can be hosted on an Azure Virtual Machine using a web server such as Nginx or Apache.

General deployment steps:

1. Create an Azure Virtual Network.
2. Create a subnet inside the virtual network.
3. Deploy a virtual machine connected to the subnet.
4. Configure the virtual machine's operating system.
5. Install and configure a web server.
6. Upload the website files to the web server directory.
7. Configure the required network security rules.
8. Allow inbound HTTP traffic on port 80.
9. Access the website using the virtual machine's public IP address.

For a public production website, configure HTTPS, a domain name if needed, and appropriate security rules.
